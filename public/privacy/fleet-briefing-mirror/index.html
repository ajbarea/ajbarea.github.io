Privacy: fleet-briefing mirror

Last updated November 17, 2026

The fleet-briefing mirror is a personal tool. It copies AJ Barea's own working notes from his computer into a folder in his own Google Drive, so his assistants can read them. It has one user: AJ Barea.

What it accesses

  • It uses Google's drive.file permission. With it, the tool can see and change only files it created itself.
  • It cannot read any other file in the Drive it is connected to.
  • It does not request access to email, contacts, calendars or any other Google data.

What it does with the data

  • It uploads copies of the notes and replaces older copies when the notes change.
  • It keeps the notes only in the owner's Google Drive and on the owner's own computer.
  • It does not send data to any other service, sell it, share it, or use it for advertising.
  • It does not use the data to train AI or machine learning models.

Google API Services User Data Policy

Its use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Stopping access

Access can be removed at any time from the Google Account's third-party access page. Removing it stops all further uploads; the files already in Drive stay there until deleted.
